Basic Computer Skills & Digital Safety
መሰረታዊ ናይ ኮምፒውተር ክእለትን ዲጂታል ደሕንነትን





Basic Computer Skills መሰረታዊ ናይ ኮምፒውተር ክእለት

1. What is a Computer? ኮምፒውተር እንታይ እዩ?

A computer is an electronic machine. It helps us learn, write, draw, calculate, and communicate.
ኮምፒውተር ኤሌክትሮኒክ መሳርሒ እዩ። ንመምሃር፣ ንመጽሓፍ፣ ንስእሊ፣ ንሒሳብን ንርክብ ሰባትን ይሕግዘና።

2. Parts of a Computer ክፍልታት ኮምፒውተር

  • Monitor / ሞኒተር: shows pictures, videos, and text / ስእሊ፣ ቪድዮን ጽሑፍን የርእይ
  • Keyboard / ኪቦርድ: used for typing letters, numbers, and symbols / ፊደላት፣ ቁጽሪታትን ምልክታት ንምፅሓፍ ይጠቅም
  • Mouse / ማውዝ: moves the pointer and selects items / ነገራት ንምምልካትን ንምምራፅን ይጠቅም
  • CPU / ሲፒዩ: the brain of the computer / ኣእምሮ ኮምፒዩተር፣ ሒሳብን መረጃን ይሕዝ
  • Speakers / ስፒከር: produce sound / ድምጺ ይህብ
  • Printer / ፕሪንተር: prints documents / ሰነድ ኣብ ወረቀት የውፅእ

3. Turning the Computer On and Off ኮምፒውተር ምኽፋትን ምዕፃውን

To turn on the computer, press the power button.
ኮምፒዩተር ንምኽፋት መድረኽ Power ፅቐጥ።

To turn it off, click “Start” → “Shut Down”.
ንምዕጻው “Start” → “Shut Down” ፅቐጥ።

4. Using the Mouse ምጥቃም ማውዝ

  • Left click = select things / ፀጋም ፅቐጥ = ነገር ምምራጽ
  • Right click = see options / የማን ፅቐጥ = ኣማራፅታት ምርኣይ
  • Scroll = move the page / Scroll ገጽ ንላዕልን ታሕትን ምንቅስቓስ

5. Using the Keyboard ምጥቃም ኪቦርድ

The keyboard has letters, numbers, and symbols.
ኪቦርድ ፊደላት፣ ቁጽሪታትን ምልክታትን ኣለዎ።

6. Basic Keyboard Shortcuts መሰረታዊ ናይ ኪቦርድ ስራሕቲ

  • Ctrl + C = Copy / ምቕዳሕ
  • Ctrl + V = Paste / ዝተቐድሐ ምቕማጥ
  • Ctrl + X = Cut / ጠቕሊልካ ምቕዳሕ
  • Ctrl + Z = Undo / ምምላስ
  • Ctrl + A = Select all / ንኹሉ ምምራፅ

7. What is the Internet? ኢንተርኔት እንታይ እዩ?

The Internet is a big network.
ኢንተርኔት ዓቢ መርበብ ሓበሬታ እዩ።
We use it to learn, watch videos, and talk to people.
ንምምሃር፣ ቪድዮ ንምርኣይን ሰባት ንምዝራብን ንጥቀመሉ።

8. Computer Safety Rules ናይ ኮምፒውተር ደሕንነት ሕግታት

• Do not share your password
• ፓስወርድኻ ንኻልኦት ሰባት ኣይተካፍል
• Do not click strange links
• ዘይፍለጡ ሊንክታት ኣይትፅቀጥ
• Ask a teacher or parent for help
• ንመምህር ወይ ወላዲ ሓገዝ ሕተት

9. Why Do We Learn Computers? ኮምፒውተር ንምንታይ ንመሃር?

We learn computers to be smart, creative, and ready for the future.
ኮምፒውተር ንመሃር ብልሓት ንምዕባይ፣ ፈጠርቲ ንምዃንን ንዝመጽእ ድልው ንክንኸውንን እዩ።

Digital Safety ዲጂታል ደሕንነት

1. What is Digital Safety? ዲጂታል ደሕንነት እንታይ እዩ?

Protect your computer, smartphone, and personal info from online threats.
ዲጂታል ደሕንነት ማለት ኮምፒውተርካ, ስልክኻን ሓበሬታኻን ካብ ቫይረስ፣ ሓበሬታ ጠለፍትን ትኽክል ዘይኮነ ሓበሬታን ምክልኻል ማለት እዩ።

2. Key Digital Safety Tips ወሰንቲ ናይ ደሕንነት መምርሕታት

  • Use strong passwords / ጠንካራ ፓስወርድ ምጥቃም

    • Create passwords with letters, numbers, and symbols. Avoid simple ones like “1234.”
    ፓስወርድካ ከም ፊደላት፣ ቁጽሪታትን ምልክታትን ምጥቃም። ቀለልቲ ፓስወርድ ከም “1234” ዘይምጥቃም።

  • Keep software updated / ሶፍትዌርካ ምምዕባል

    • Updates fix security problems. Always update your system and apps.
    ምዕባለታት ሶፍትዌር ናይ ደሕንነት ፀገማት ይፈትሕ። ስለዚ ሲስተምካን ኣፕሊኬሽንካን በብግዚኡ ምምዕባል

  • Avoid suspicious links / ዘይፍለጡ ሊንክታት ዘይምንካእ

    • Do not click on unknown emails or pop-ups. They may contain malware.
    ዘይፍለጡ ኢሜል ወይ ፖፕ-አፕ ዘይምንካእ። ዘየድሊ ሓበሬታ ዝሓዙ ክኾኑ ይኽእሉ እዮም።

  • Use Antivirus / ፀረ ቫይረስ ምጥቃም

    • Antivirus programs detect and remove harmful software.
    ፀረ ቫይረስ ፕሮግራማት ጎዳእቲ ሶፍትዌራት የለልዩን የጥፍኡን።

Basic Software Installation መሰረታዊ ናይ ሶፍትዌር ኣፀዓዕና

1. Steps to Install Software ቅደም ሰዓብ ሶፍትዌር ኣፀዓዕና

  • Download from official site / ናብ ትኽክለኛ ዌብሳይት ብምኻድ ምውራድ

    • Go to the official website and download the software. Avoid unknown sites.
    ናብ ትኽክለኛ ዌብሳይት ብምኻድ እቲ ሶፍትዌር ምውራድ። ዘይፍለጡ ዌብሳይታት ዘይምጥቃም።

  • Run Installer / ዝወረደ ሶፍትዌር ምጅማር

    • Double-click the downloaded file to start installation.
    ዝወረደ ሶፍትዌር ክልተ ግዜ ብምንካእ ምጅማር።

  • Follow instructions / መምርሕታት ምትግባር

    • Choose language, installation location, and accept terms. Click “Next” until finished.
    ቋንቋ ምረጽ፣ ቦታ ምረጽ፣ መስርሓት ምቕባል። ክሳብ ዝውድእ “Next” ምፅቃጥ።

  • Finish & Launch / “Finish” ዝብል ምፅቃጥ ናብ ሶፍትዌር ምጥቃም

    • Click “Finish” and open the software to use it. “Finish” ዝብል ምፅቃጥን ሶፍትዌር ብምኽፋት ምጥቃምን።

Introduction to Programming መእተዊ ንፕሮግራሚንግ

1. What is Programming? ፕሮግራሚንግ እንታይ እዩ?

Programming is the process of giving instructions to a computer to perform specific tasks. These instructions are written in a language that the computer can understand, called a programming language.
ፕሮግራሚንግ ማለት ንኮምፒውተር መምርሕታት ብምሃብ ዝተፈላለዩ ስራሕትታት ንክሰርሕ ምግባር እዩ። እዞም መምርሕታት ዝፀሓፉ ንኮምፒውተር ብዝርደኣ ቋንቋ እዩ። እዚ ቋንቋ ፕሮግራሚንግ ላንጉጅ ይበሃል።

2. Why Learn Programming? ንምንታይ ፕሮግራሚንግ ንመሃር?

  • Automate tasks and save time.
    ስራሕትታን ንምውጋንን ግዘ ንምቑጣብን።
  • Solve problems logically.
    ፀገማት ንምፍታሕ።
  • Build software, apps, websites, and games.
    ሶፍትዌራት, ኣፕሊኬሽናት, ዌብሳይታትን ጌማትን ንምስራሕ።
  • Open career opportunities in technology.
    ናብ ናይ ቴክኖሎጂ ዓውዲ ንምፅንባር።

3. Key Concepts in Programming ቁልፊ ሓሳባት ኣብ ፕሮግራሚንግ

  • Program ፕሮግራም
    • A set of instructions given to a computer ንኮምፒውተር ዝወሃብ መምርሕታት
  • Algorithm ኣልጎሪዝም
    • Step-by-step method to solve a problem ፀገማት ንምፍታሕ ንኽተሎም ቅደም ሰዓብ መንገድታት
  • Variable ቫሪያብል
    • Storage for data ናይ ሓበሬታ መቐመጢ ቦታ
  • Function ፋንክሽን
    • A reusable block of code ደጋጊምና እንጥቀመሉ ናይ ኮድ እኩብ
  • Loop ድግግም
    • Repeat tasks multiple times ስራሕትታት ደጋጊምኻ ምስራሕ

    4. Popular Programming Languages ፍሉጣት ቋንቋታት ፕሮግራሚንግ

    • Python:- Easy to learn, used for web, AI, and data science.
      ፓይተን- ንምምሃር ቀሊል, ንዌብሳይት ንሰብ ሰራሕ ብልሒን ን ሳይንስ ሓበሬታን ንምስራሕ ይጠቅም።
    • Java:- Used for apps and large systems.
      ጃቫ- ንዓበይቲ ሲስተማትን ንኣፕሊኬሽናትን ንምስራሕ ይጠቅም።
    • C/C++ :- Used for system software and performance-critical tasks.
      ንሲስተም ሶፍትዌራትን ብቑዓት ስራሕትታት ንምስራሕ ይጠቅም።
    • JavaScript:- Used for web development and interactive websites.
      ጃቫስክሪፕት - ዌብሳይታት ንምስራሕ ይጠቅም።

    5. Writing Your First Program ናይ መጀመርታ ፕሮግራም ምፅሓፍ

    • Python ፓይተን
      • print("Hello, World!")
      This program prints “Hello, World!” on the screen.
      እዚ ፕሮግራም መልእኽቲ “Hello, World!” ኣብ ስክሪን የርእይ።

    6. Steps to Learn Programming ቅደም ተኸተል ትምህርቲ ፕሮግራሚንግ

    • Choose a programming language ፕሮግራሚንግ ቋንቋ ምምራፅ
    • Learn basic concepts: variables, loops, functions ቁልፊ ሓሳባት ምምሃር
    • Practice writing small programs ቀለልቲ ፕሮግራማት ብምፅሓፍ ምልምማድ
    • Solve problems online ፀገማት ምፍታሕ
    • Build projects ፕሮጀክት ምስራሕ

Stories of 10 Successful People in Technology ታሪኽ 10 ዕውታት ሰባት ኣብ ቴክኖሎጂ

Introduction መእተዊ

Technology has transformed the world, and many individuals have achieved great success by combining innovation, hard work, and persistence. Today, we will explore the stories of 10 influential tech leaders and the lessons we can learn from them.
ቴክኖሎጂ ዓለምና እናቐየረ ዝርከብ ዓውዲ እዩ። ብዙሓት ሰባት ድማ ኣብ ቴክኖሎጂ ብምፅምባር ዕውታት እናኾኑ ይርከቡ። ካብኣቶም ናይቶም 10 ሰባት ታሪኽን ካብኦም እንመሃሮ ነገርን ክንርኢ ኢና።

1. Elon Musk ኤሎን መስክ

Founder of Tesla, SpaceX, and other companies. Musk faced many failures, including rockets exploding and financial struggles, but his persistence turned bold ideas into reality.
Lesson: Think big, take risks, and never give up.
መስራቲ ድርጅታት ቴስላ, ስፔስ ኤክስን ካልኦትን። መስክ ብብዙሕ ማሕለኻታትን ስሕተታትን ዝሓለፈ ኮይኑ ክሳብ ምፍንጃር ሮኬትን ፋይናንሳዊ ፀገማትን ሓሊፉ ከበድቲ ሓሳባት ናብ ክዉንነት ዝቐየረ እዩ።
ካብ መስክ ንወስዶ ትምህርቲ - ዓብይ ምሕሳብ, ስግኣታት ምቅላስን ተስፋ ዘይምቑራፅን

2. Steve Jobs ስቴቭ ጆብስ

Co-founder of Apple. Jobs emphasized simplicity, beauty, and usefulness in products. Even after being removed from Apple, he returned and revolutionized technology with the iPhone and iPad.
Lesson: Focus on creativity and quality.
ኣባል መስራቲ ድርጅት ኣፕል። ስራሕትታት ናይ ውፅኢታት መልክዕን ጠቓምነትን ዝውስኑ እዮም። ዝተመሓየሹ ኣይፎናትን ኣይፓድን ዝፈጠረ እዩ።
